## Requirements

- Retoswap https://retoswap.com
- `./haveno-statsnode --dumpStatistics=true`
- create .env from .env.example
- `bun run db:push`  
  for dev:
- `bun run dev`  
  for prod:
- `bun run build && bun ./build/index.js`
